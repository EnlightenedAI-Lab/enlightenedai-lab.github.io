Operational safeguard

Every rule requires human review and a complete, authorized data source. Emergency, protected-operation and automated ALPR records are explicitly excluded from irrelevant detectors in this demonstration.

Data contract & assumptions

A proposed audit schema, not a claim about actual CPIC log fields.

Minimum event contract

REQUIRED FOR DEMO
  • Query event ID and accurate timestamp
  • Pseudonymous user / actor key
  • Query category and target token
  • Manual versus automatic query mode
  • Source provenance and completeness marker
CONDITIONAL CORRELATION
  • Shift and call-out records
  • Dispatch / CAD correlation identifier
  • Case / occurrence reference and case scope
  • Assigned or approved device inventory
  • Approved exception classification
All actual availability, legal authority, classification, retention, governance and interfaces require RCMP verification. No GPS is collected or needed for these six demonstration rules.

Explicit limits

Unknown event context is not interpreted as non-compliance. Automated ALPR scan events are not conflated with officer-initiated database searches. Protected operations and emergencies are excluded from simplistic rules. Real deployment needs access control, approved hosting, security assessments, privacy review, independent validation and tamper-evident audit infrastructure.
